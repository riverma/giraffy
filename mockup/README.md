# The mockup

`Giraffy.dc.html` is the interactive prototype the production app was built from: every
screen, every state, and all the copy, signed off before the rebuild began. It is kept here
as the design record. The app in `src/` is the thing that ships.

The mockup is not part of the build and is not deployed. It renders in a design-composer
runtime whose files (`support.js`, `ios-frame.jsx`, and the whole `_ds/` design-system
directory) are not ours to redistribute, so none of them are in the public history. Without
them this file will not render; the screenshots here and in `spec/SPECIFICATION.md` carry the
same information.

`screenshots/` holds four frames from the mockup as it was signed off: the welcome page, the
People list, Settings, and the Insights tab that v0.6 removed.

Where the app and the mockup disagree, the mockup and `spec/SPECIFICATION.md` v0.6 win.
